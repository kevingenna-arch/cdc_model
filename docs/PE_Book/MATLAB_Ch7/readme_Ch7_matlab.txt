Readme.txt: Chapter 7
=====================

In order to run, you need to install all files in the same directory.

1. Ch7_data.m
=============

computes the statistics and figures in Chapter 7.1

uses various excel input files (need to be stored in the same directory)


2. Ch7_debt1.m
==============

computes Figure 7.10 for the OLG model with debt


3. Ch7_US_debt.m and Ch7_US_debt_transition.m
=============================================

compute the dynamics and the steady state in the large-scale OLG
model for the US from Chapter 7.5.

copy all files from the subdirectory \Ch7_US_debt\ into a new directory and start 
Ch7_US_debt.m, which generates Fig. 7.11

the run time for Ch7_US_debt.m amounts to a couple of minutes depending on the matlab 
version that you are using.

next, start ch7_US_debt_transition.m for policy=0, which is the benchmark case. Run time 
amounts to 33 minutes on my PC using Matlab R2013. For later releases, run time may
be much higher.

Next compute the policies policy=1, policy=2, and policy=3. Run time increases to approx
4 hours for policy=2 and policy=3.

The output is saved into the matlab-file "Ch7_US_debt_transition.mat". The figure is
generated by '"Ch7_transition_figure.m'.

Remarks: In the GAUSS program, the non-linear eqs solver finds a root for the final steady 
state using the values of the initial steady state as input. fsolve() in matlab does not
converge. Therefore, I just copied the solution from 
the GAUSS program Ch7_US_debt_transition.g.
