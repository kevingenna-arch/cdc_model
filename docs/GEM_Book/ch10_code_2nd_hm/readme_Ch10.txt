Computer Programs Chapter 10,
2nd edition Heer/Maussner, Dynamic General Equilibrium Modeling
===============================================================

- store all GAUSS computer programs in the same directory

- if you want to save/load data in/from a different directory,
you need to specify the save/load path in the top of the program

- you need to store the files 'ef.fmt', 'ef1.fmt' and 'sp2.fmt' in the load path,
 if the load path is not specified, you need to store them in the same
directory as the GAUSS programs

- the programs need ch8_toolbox.src and olg1.src as input files; therefore 
the two programs need to be stored in the same directory
