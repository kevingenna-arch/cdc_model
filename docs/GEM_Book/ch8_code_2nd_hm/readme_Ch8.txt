Computer Programs Chapter 8,
2nd edition Heer/Maussner, Dynamic General Equilibrium Modeling
===============================================================

- store all GAUSS computer programs in the same directory, if possible
in the same directory as those from Chapter 7

- RCh8_gues.g needs the output from the program RCh7_disf.g, which is 
automatically saved in the same directory of RCh7_disf.g if no other save
path has been specified in the top of the program RCh7_disf.g

- if you want to save/load data in/from a different directory,
you need to specify the save/load path in the top of the program

- the program RCh83cas1.g needs ch8_toolbox.src as an input file; therefore 
the two programs need to be stored in the same directory
