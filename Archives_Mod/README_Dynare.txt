Ce dossier contient des fichiers dynare (.mod). Ils capturent l'evolution progressive de la maquette CDC.

ATTENTION: ces modeles peuvent contenir des erreurs. Ils ont pour vocation de mieux comprendre comment modeliser chaque composante de la maquette CDC.

olg     : overlapping generation model
MultiT  : introduction d'un nombre de generation superieur a  10
LS      : introduction du travail endogene
P       : introduction d'un module de population
Pub     : introduction d'un compte public plus detaille (dette, deficit, taxes et pensions)
health  : introduction d'un module de sante
educ    : introduction d'un module d'education
pen     : introduction d'une pension indexee sur les salaires passes
sk      : introduction de deux niveaux de qualification (choix exogène) dans les maquettes MultiT
skendo      : introduction de deux niveaux de qualification (choix endogène) dans les maquettes MultiT
